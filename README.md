# Flutter SQLite

End code for the SQLite basic lesson.

Clone the repo:

```bash
git clone git@github.com:yeasin50/flutter_workshop.git
cd flutter_workshop
git checkout sqlfite_start
```

You can also clone using the HTTPS URL:

```bash
git clone https://github.com/yeasin50/flutter_workshop.git
```

Create missing platform files if needed:

```bash
flutter create .
```

Install dependencies and run:

```bash
flutter clean
flutter pub get
flutter run
```

For the completed version:

```bash
git checkout sqlfite_basic_end
```
